# Answer key: drafting and review for Installation and Getting started

Written BEFORE checking the Doc drafter v7 and Style guide reviewer v5 runs on Briefs 1–5 in `examples/install-getting-started/02-doc-plan.md`.

## Drafter: what must hold for every draft

| Check | Why |
|---|---|
| Uses the brief's title and headings, in order, and doesn't add or drop any | Drafter rule |
| Headings are short labels (house-style v1.2, rule 7) | New rule |
| Every sentence has an [S#] tag, and there are no evidence notes (R4, Passed) | Shared contract |
| No invented facts | The core claim |
| GAPs point to the existing I-Q and P-Q numbers, without repeating them | "Already asked" |

## Facts the drafter must NOT supply (no source; expect a GAP or nothing)

- Where to get ContosoChartsSetup.exe (I-Q1)
- What a user without administrator rights sees (I-Q2)
- Whether you need to close PowerPoint before an update (I-Q3)
- What happens to charts after uninstall (I-Q5)
- How to reopen the Welcome pane (I-Q6)
- What Chart Styles and Color Palette do (intake didn't ask, so the drafter should)
- How to select a range in the Link to Excel dialog box (I-Q9)
- Brief 3's "What Contoso Charts does" section, which says to keep the existing content. The drafter has no existing text, so it should leave the section unchanged or GAP it, not invent a product description.

## Facts that must appear, with the exact labels

- **Brief 2:**
  - the 8 install steps
  - the "Close PowerPoint to continue." message
  - "I accept the agreement"
  - Browse, Install (and the progress bar), Finish
  - the Welcome pane
  - the update and uninstall paths for Windows 11 and Windows 10
- **Brief 3:** the four groups with their exact buttons, and New Chart (not Insert Chart).
- **Brief 4:**
  - New Chart and the Choose a Chart Type dialog box
  - all five chart types, including Area
  - Insert, then sample data
  - Edit Data
- **Brief 5:**
  - Link to Excel and the Link to Excel dialog box
  - browse, select the range, then OK
  - Edit Data is unavailable after linking

## Reviewer (v5 with house-style v1.2)

- It should flag any heading longer than 4–6 words, or any heading that reads as a sentence. Intake's titles were long, but the briefs should already have fixed them.
- It should not flag the brief's kept web titles ("Install Contoso Charts," "Link a chart to Excel data") as rule 7 violations if they're 4–6 words.
- Expect few issues: the drafter writes to the same house style.
